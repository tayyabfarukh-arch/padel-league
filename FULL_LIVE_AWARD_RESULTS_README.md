# Full Live Monthly Award Results

This update expands the live monthly voting results in **Admin > Awards**.

## What the Admin can see

- Number of players who participated.
- Total number of votes recorded across all monthly categories.
- Every player who received a vote in each category.
- Exact vote count and percentage for each player.
- Current leader or tied leaders.

Scroll sideways to move between award categories. If a category has many vote recipients, scroll inside that category to see the complete list.

Results refresh automatically every 15 seconds. Press **Refresh** for an immediate update.

The dashboard does not reveal who cast each vote. It shows only combined totals.

## Deployment

Upload everything inside the new ready-to-upload folder to the root of your GitHub repository. Replace the existing files when GitHub asks.

Netlify will deploy automatically.

## Supabase and Netlify

No Supabase SQL update and no new Netlify environment variable are required.
