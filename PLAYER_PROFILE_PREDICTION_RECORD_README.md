# Player Profile Prediction Record

Every public player profile now displays:

- Correct predictions
- Wrong predictions
- Prediction accuracy

The totals include the player's submitted predictions for completed tournaments that have a confirmed champion. Upcoming and active predictions are not counted until the tournament is completed.

## Deployment

1. Upload everything inside the new ready-to-upload folder to the root of the GitHub repository.
2. Replace files with the same names.
3. Commit the upload.
4. Wait for Netlify to display **Published**.

No Supabase SQL update or new environment variables are required.
