# Live Monthly Award Voting Leaders

This update adds a small live-results area to **Admin > Awards**.

## What you will see

1. Open the website and sign in as Admin.
2. Open **Admin**.
3. Open the **Awards** section.
4. Under the open monthly vote, scroll the **Live voting leaders** row sideways.
5. Each award shows the player currently leading and the total number of votes received.
6. If players are tied, the card says **Currently tied** and shows the tied leaders.

The results refresh automatically every 15 seconds. You can also press **Refresh** for an immediate update.

Individual votes remain private. The Admin can see only the combined totals and current leaders.

## Deployment

Upload everything inside the new ready-to-upload folder to the root of your GitHub repository, replacing the existing files when GitHub asks.

Netlify will deploy automatically after the upload finishes.
