# Player Pickers, Account Page, and Admin Table Update

## What changed

- Every player selection now shows the player's profile picture and name.
- Player selections are searchable.
- The Account page now has separate Overview, Details, and Profile sections.
- Signed-in players can open their public profile directly from the Account page.
- Admin sign-ups are displayed in a proper table with separate columns.
- Clicking a linked player in the Admin table opens that person's public profile.

## Supabase

No new SQL is needed for this update. Do not delete or rerun your existing data.

## Deploy to GitHub and Netlify

1. Open the new ready-to-upload folder supplied with this release.
2. Upload everything inside that folder to the root of your GitHub repository.
3. Choose the option to replace files with the same names.
4. Commit the upload.
5. Netlify will start a new deployment automatically.
6. Wait until Netlify displays **Published**.

No new Netlify environment variables are required.
