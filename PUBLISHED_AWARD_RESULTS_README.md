# Published Monthly Award Vote Breakdown

This update keeps the complete monthly vote results visible after the Admin closes and publishes the voting.

## Where to find the results

1. Sign in as Admin.
2. Open **Admin**.
3. Open the **Awards** section.
4. Scroll to **Published history**.
5. Open or view the relevant monthly award period.
6. Scroll sideways through the award categories.

Each category shows every player who received votes, their exact vote total, percentage, and final ranking. The summary also shows the number of participants and total votes.

The layout uses the full width of the Admin panel so it is easier to capture and share screenshots in WhatsApp.

## Deployment

Upload everything inside the new ready-to-upload folder to the root of your GitHub repository. Replace the existing files when GitHub asks.

Netlify will deploy automatically.

## Supabase and Netlify

No Supabase SQL update and no new Netlify environment variable are required.
