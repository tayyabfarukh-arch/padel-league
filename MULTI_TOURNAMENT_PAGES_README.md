# Multi-Tournament Upcoming and Active Pages V46

The Upcoming and Active navigation tabs now support more than one tournament with the same status.

- When two or more tournaments are available, a chronological selector appears at the top.
- Selecting a tournament loads its complete page underneath without changing its status.
- Upcoming tournaments retain registration functionality and hide score entry.
- Active tournaments retain score submission functionality.
- A single tournament continues to open directly without an unnecessary selector.

No Supabase SQL update is required.
